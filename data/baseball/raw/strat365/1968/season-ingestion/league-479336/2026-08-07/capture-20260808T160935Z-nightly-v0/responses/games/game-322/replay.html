Welcome to the Strat-O-Matic Game Replay


Now, you can watch last night's games - or any past game ever! - unfold play by play, or inning by inning, or at whatever pace you wish, with the new Strat-O-Matic Game Replay! Just click on the binoculars icon () next to any past game to start the show. The playback will begin automatically after the page finishes loading.

Controls / Features

- Press the Pause button in the upper left corner of the baseball field display to pause the action.
- While paused, press the button again (Play) to resume the action.
- Set the playback speed using the slider under the field display.
- Click on the Skip button (next to the Play/Pause button) to fast-forward to the start of the next half-inning.
- Click on any half-inning in the line score to seek to the start of that half-inning.

Beta

Game Replay is currently in Beta, which means it has not been rigorously tested and is unlikely to be free of bugs. If you watch games normally without clicking excessively on the Play/Pause and Skip buttons, the Game Replay should work fine for you.

Note: The Game Replay is known to have problems running on earlier versions of Internet Explorer. Please upgrade to the latest version of IE if you can't get it to run at all, or use another browser such as Chrome, Firefox, or Safari.

While the Game Replay is running, the kind of issues you may run into (if at all) would likely include:

- Play-by-play lines appearing twice in the event window.
- The Skip button not taking you all the way through to the end of the half-inning. In this case, just click the button again.
- An unrecognized type of play. Please report any plays you find that are not handled as expected.
- A pinch-runner replaces the wrong runner. Unfortunately, the standard play-by-play report generated by the game engine doesn't specify which player a pinch-runner is replacing if there's more than one possibility. Since Game Replay simply parses the play-by-play report, in these cases it has no other (feasible) choice but to assume that the pinch-runner is replacing the lead runner, which obviously will be incorrect sometimes.

In general, these types of problems are more likely to occur if you play around with the controls while playback is running. The Skip button and the seek-to-half-inning controls automatically Pause the action when you arrive at your destination, so you'll usually be Paused while using them during normal operation.

If you encounter a problem with the Game Replay, or you just have a suggestion, please drop us a line at 365support@strat-o-matic.com, and be sure to include a link to the game in question.
